⚠️ 使用前必读

严禁用于营业性商业目的：本项目只用于管理你自己的账号，把个人账号额度接到自己的客户端上。 不提供、也禁止任何形式的对外售卖、代充、批量注册、共享号池运营或二次转卖 API。用它做生意导致的上游封号、 欠费与法律风险由使用者自行承担。
每个号池建议最多绑 3 个账号：同一个上游（WorkBuddy / Trae / ZCode / AutoClaw / Qoder / Google） 塞太多账号并不会更快，反而更容易触发同 IP 风控与关联封禁；超过 3 个后收益极小，风险成倍上升。 先用 1~2 个跑顺，需要更多并发再逐个加。
本项目由纯 AI 制作，主要集成两个开源项目：核心思路与大量实现来自 agentpoints（workbuddy2api-panel 一系）与 AIClient2API（Google/Antigravity 反代规范）。作者没有能力对全部路径做海量测试验证， 上游接口改动、模型增删、Agent 版本差异都可能导致某个功能失效或报错。
欢迎提 issue / 报 bug：遇到问题请带上请求日志页的错误分类与渠道（不含对话内容），越具体越好。 如果你只是想把模型用起来、希望更稳，建议直接用 agentpoints 或 AIClient2API 原项目—— 它们维护更久、社区验证更多；本项目定位是「自己折腾、能省一点是一点」。

添加账号（按渠道）

Google（Antigravity）：点「添加账号 → Google」浏览器授权即可，client 凭据已内置；也可粘贴 AIClient2API 的 *_oauth_creds.json。
WorkBuddy（腾讯 CodeBuddy）：「添加账号 → WorkBuddy」选国内版/国际版 → 登录腾讯 → 自动入库；或粘贴 auths/*.json 原格式。
Trae CN：「添加账号 → Trae」获取 trae.cn 登录链接 → 浏览器登录 → 自动换 token 入库。
ZCode（Z.AI）：「添加账号 → ZCode」→ z.ai 授权 → Coding Plan JWT 自动入池。
AutoClaw（智谱）：「添加账号 → AutoClaw」输手机号收短信验证码登录；也可用「导入 JSON」粘贴凭据文件。登录/签到/钱包接口需要在 config.json 的 channels.autoclaw.app_secret 填入客户端签名常量（源码不随附）。
Qoder（阿里）：「添加账号 → Qoder」粘贴个人访问令牌（pt- 开头，来自 Qoder 个人设置 → 服务集成 → 个人访问令牌），校验通过即入池。
账号身份规则：主键取上游稳定身份（uid/邮箱/JWT sub），改备注名/换 token 都不会产生重复账号。
加号建议：每个号池最多 3 个账号。同 IP 下账号越多，关联风控与封号概率越高；先 1~2 个跑顺，再按并发需要逐个加。

日常使用

启动/停止：scripts\start-all.cmd / scripts\stop-all.cmd；开机自启在「设置 → 服务管理」。
签到与任务：任务中心自动跑签到（默认 9/21 点）+ 成长任务 + 额度刷新 + Token 预刷新；时点与间隔在任务中心页可改、保存即生效，也可手动「立即运行」。
调度逻辑（自动）：Google 号按配额窗口贪婪打分；积分号按实测免费优先 → 快过期加权 → 余额比例加权；同一对话粘住同一账号；全部账号忙时排队不漂移。
省钱要点：客户端默认模型选 flash 级（deepseek-v4-flash / glm-5.3-flash），复杂任务再手动切旗舰；用量统计页可核对每模型实际消耗。
遇到问题：请求日志页看每次调用的渠道/账号/错误分类；账号行的「刷新额度」可手动探测上游余额。

出境链路：Google / OpenCode 慢怎么办

国模（WorkBuddy / Trae / ZCode / AutoClaw / Qoder）走国内直连；只有 Google（Antigravity） 与 OpenCode 免费模型 需要出境。若这两条链路的第一字耗时异常大 （比如 >30s），而国模正常，问题几乎都在你自己的代理出口，不在网关。
最常见的根因：Windows 默认 TCP 拥塞控制是 Cubic，在 150~300ms 的跨国链路上， AI 那一两 MB 的上下文上传会被压到 0.5~1 Mbps（几十秒才发完），看起来像模型卡死。
三步处理：① 管理员终端执行 netsh int tcp set supplemental template=internet congestionprovider=bbr2 （实测 2MB 上行 18s → 3s）；② 代理分流只让 googleapis.com / opencode.ai / models.dev 出境，国模域名与 GEOIP,CN 直连；③ 关掉浏览器安全 DNS（DoH）与实验性 QUIC。
完整命令、回滚方式、分流规则与验证流程见项目内文档 docs/跨国外网出口与BBR2调优.md（面板不内置代理配置，避免把凭据带进仓库）。

试验功能（默认关）

默认关。Google 的 Gemini 3 在工具调用上附带思维链签名，回放历史时必须带回：关闭时网关填占位签名（能跑通，但模型接不回原思维链，上游提示可能轻微降智）；开启后网关截获真签名、下一轮自动回填，模型可无缝续接。试验性质：换号/换模型后旧签名可能失效（失效时的表现与关闭状态相同，都会报 400），仅影响 Google 渠道的多轮工具调用。

排队与容灾（改后需重启服务生效；scripts\stop-all.cmd → start-all.cmd）

所有账号都在忙时，请求原地排队多久才报忙。默认 120。超时后客户端收到 429。
同一模型绑定多个渠道时，第一个渠道最多等多久就换下一个渠道。默认 8。
同一个对话记住同一个账号多久（缓存命中更省）。默认 30 分钟。
记下"某账号某模型是否扣积分"后，这个观测保留多久。默认 6 小时。
请求日志/任务记录保留天数，过期自动清理。默认 14。
这些参数保存在 config.json，保存后自动重启服务（约 5 秒）。
